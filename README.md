# Pringles — Website Concept

Conceito não oficial de site institucional para **Pringles**, desenvolvido como estudo de front-end, identidade visual e motion design para web.

## Objetivo

Criar uma experiência digital inspirada na linguagem visual da marca, dando destaque aos sabores e utilizando animações para tornar a navegação mais dinâmica.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- SplitType

## Destaques

- Apresentação visual de diferentes sabores
- Animações com GSAP
- Efeitos vinculados ao scroll
- Animações de texto
- Seções promocionais com forte identidade visual
- Interações desenvolvidas em JavaScript

## Estrutura

```text
.
├── assets/
├── index.html
├── script.js
└── style.css
```

## Aprendizados

Durante o desenvolvimento, o projeto serviu para praticar:

- adaptação de identidade de marca para interfaces web;
- animação de elementos e textos;
- composição de seções promocionais;
- manipulação do DOM com JavaScript;
- criação de experiências visuais mais dinâmicas.
